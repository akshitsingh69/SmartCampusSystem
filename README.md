# Smart Campus Resource Management System

## 📌 Project Overview

The **Smart Campus Resource Management System** is a Java-based console application designed to manage students, campus resources, and resource bookings efficiently. The project is developed as part of the VITyarthi “Build Your Own Project” evaluation and demonstrates the practical application of Java programming concepts.

The system provides a simple and interactive menu through which users can add and search students, manage campus resources, book resources, view bookings, and generate basic analytics.

## 🎯 Objectives

* Apply Java fundamentals to a real-world problem.
* Demonstrate major Object-Oriented Programming concepts.
* Implement resource booking and management.
* Handle errors using exception handling.
* Demonstrate multithreading and synchronization.
* Develop a modular and maintainable Java application.

## 🚀 Features

1. **Student Management**

   * Add students
   * View student details
   * Search students using ID
   * Sort students alphabetically

2. **Resource Management**

   * Add campus resources
   * View resource availability
   * Book available resources
   * Prevent duplicate bookings

3. **Analytics**

   * Display total students
   * Display total resources
   * Display total bookings
   * Display available and booked resources

4. **Multithreading**

   * Simulates multiple students attempting to book the same resource.
   * Uses `Runnable`, `Thread`, `synchronized`, `sleep()` and `join()`.

## 🛠️ Technologies Used

* **Language:** Java
* **Concepts:** OOP, Collections, Exception Handling, Generics, Multithreading
* **Data Structures:** ArrayList, HashMap
* **Tools:** JDK, VS Code/IntelliJ IDEA/Eclipse, Git & GitHub

## ▶️ Installation & Execution

Clone the repository and open the project directory.

Compile the program:

```bash
javac SmartCampusSystem.java
```

Run the application:

```bash
java SmartCampusSystem
```

## 🧪 Testing

The application can be tested by adding students and resources, searching students, booking resources, attempting duplicate bookings, and running the multithreading demonstration.
